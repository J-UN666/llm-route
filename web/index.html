项目说明

项目背景

立足城市交通出行、校园通勤、便民交通服务的轻量化场景痛点，针对传统交通服务软件开发周期长、功能固化、小众场景适配性差、运维成本高的问题， 依托 LLM Agent 智能体技术与 OPC 个人公司实践模式，面向本科生开展智慧交通类 APP 全流程开发与创业实践。

核心工具

以 Claude、龙虾 Skill（OpenClaw）为核心开发工具，结合交通行业高频刚需场景，打造轻量化、可迭代、个性化的智慧交通服务系统。

本原型范围

聚焦西南交通大学犀浦校区及"犀浦 → 成都各地"的校内—城市一体化路线规划：校内步行段用本地候选路网计算， 城市段以地铁接驳方案呈现。校园班车、施工提示等模块以信息卡形式接入。

技术栈

  • 数据层 校园公开数据包（OSM + 官方目录，2026-11-03）
  • 算法层 A* 最短路 + 多方案（稳妥/最短）+ 校门方位选择
  • Agent 层 意图解析 → 7 个工具编排 → 结果生成
  • 渲染层 Canvas 轻量矢量地图（离线可用，无需 CDN）

合规与免责

OSM 数据遵循 ODbL 1.0，展示需保留 © OpenStreetMap contributors 署名。学校官网图件未找到明确开放数据许可， 本原型仅作校内教学与竞赛演示，不用于商业发布。城市段地铁/公交信息为人工整理的公开常识，未经本项目核验， 正式出行请以官方地图服务为准。校车时刻为 2022 年历史数据，默认禁止作为实时班次推荐。
