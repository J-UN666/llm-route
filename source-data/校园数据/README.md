# 交大智行｜犀浦校区公开数据包

采集日期：**2026-11-03**。范围为西南交通大学犀浦校区、紧邻校门的交通接驳点，以及与项目有关的校车和施工通知。以公开、可复核的稳定资料为主，供2–4周项目开发使用。

本次已覆盖官方位置平台中选定的公开建筑和生活设施目录，并提取校园及周边有界OSM地图。它不是校方全量业务数据库，也不代表已穷尽互联网所有校园资料。未访问校内登录系统或收集学生、宿舍住户信息。

## 清洗做了什么

1. 保留来源名称，另生成统一Unicode、空格和括号形式的检索名称；未知位置和未提供字段保留为`null`，没有填0或编造名称。
2. 官方目录原有27条建筑/组团、173条公开设施。逐分类核对173条设施与平台公布数量一致；仅合并1组名称、类别、坐标完全相同的重复设施，最终199条。去重保留所有原始记录编号。
3. 别名分为来源规范化名称和项目配置的搜索词。项目配置的“一教”等词不是新增官方数据。同名站台、同名校门不按名字强行合并。
4. OSM按校园边界筛选内部地点和建筑；校外同名学校设施另存`nearby_campus_named_osm`。道路按相邻节点拆边，保留权重来源、权限、桥隧与层级。18条跨校界边段显式标记，没有伪造校门连接。
5. 坐标严格分开：OSM为WGS84；官方矢量坐标保留`UNDECLARED`，原图示意坐标不进入地理坐标列。没有尝试猜测并自动纠偏。
6. 校车历史、增量变更、施工计划、接驳文字证据分别存表，不覆盖稳定地点表，不拼成“当前有效”的完整数据。
7. 整理阶段已校验主键、外键、坐标范围、分类数量、重复、正距离和来源文件哈希；过程日志已删除，结果摘要保留在[数据质量说明](数据质量与待核实.md)。结构检查通过不等于现实路线已经验证。

## 项目现在能做到什么

可以先完成：地点搜索和消歧、地图展示、起点/校门选择界面、交通接驳信息卡、候选路网算法演示、带日期的校车与施工参考信息。城市段路线仍按项目方案交给地图服务查询。

真实“楼宇入口 → 校门 → 城市站点”路线的第一步，是从10个候选地点中挑6–10个，实地补入口，确认两个校门与OSM节点的对应关系，再验证接路边。不要直接用楼中心连最近道路。

当前没有：校车实时GPS/到站、停车余位、闸机实时状态、全量精确施工围挡、已确认的2026完整校车时刻表。鸿哲斋2/3已有官方名称证据，但本包不编造其入口坐标。

## 后续更新

本包保留2026-11-03整理的数据版本。需要更新时，从`sources.json`记录的公开来源重新核对，并保留新旧数据版本；来源内容不会随本地文件自动更新。校园平台接口不是已承诺稳定的开放API，不应作为产品运行时依赖或高频轮询来源。
